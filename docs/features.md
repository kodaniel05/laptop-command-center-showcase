# Features

## Dashboard

The dashboard gives the user a current operational view of laptop storage health. It combines scan freshness, review queues, smart folders, storage snapshots, and scan warnings into one place.

Screenshot placeholder: `images/screenshots/dashboard-home.png`

## Local Scan Workflow

The scan workflow indexes local metadata and builds summaries for storage categories, review queues, smart folders, folder sizes, app storage, and warnings. It is designed to handle partial results and protected locations gracefully.

Screenshot placeholder: `images/screenshots/scan-progress.png`

## Document Review

The document review workspace organizes files by review status and cleanup queue. Users can filter by old files, school-related files, downloads, repeated files, large files, screenshots, and installers.

Screenshot placeholder: `images/screenshots/document-review-workspace.png`

## Smart Folders

Smart folders group files by cleanup intent instead of raw directory structure. This helps the user move from "where are my files?" to "what should I review next?"

Screenshot placeholder: `images/screenshots/smart-folders.png`

## Storage Analytics

Storage analytics show category-level and folder-level summaries so users can understand where space is going before acting.

Screenshot placeholder: `images/screenshots/storage-analytics.png`

## Search

The search drawer supports indexed lookup across files, folders, apps, smart folders, and review candidates, with filters and sort modes designed for triage.

Screenshot placeholder: `images/screenshots/search-drawer.png`

## File Actions

File actions support guarded workflows such as reveal in Finder, mark as Keep, mark as Delete candidate, return to Review, and copy selected files into review folders.

Screenshot placeholder: `images/screenshots/file-action-confirmation.png`

## History

The history view helps users understand scan coverage, indexed storage, and how the local scan state changes over time.

Screenshot placeholder: `images/screenshots/scan-history.png`
