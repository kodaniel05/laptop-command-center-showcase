# Future Improvements

## Custom Smart Folders

Allow users to turn searches and filters into persistent smart folder rules.

## Stronger Duplicate Detection

Add content-aware fingerprints or hashes for duplicate detection while preserving local-first privacy.

## Background Scanning

Support more configurable scan scheduling, background refresh behavior, and scan throttling.

## Storage Trend Analytics

Add historical charts for storage growth, reviewed files, kept files, delete candidates, and category-level changes.

## Safer Cleanup Workflows

Introduce staged cleanup sessions, undo windows, and clearer separation between review status and destructive file operations.

## Exportable Reports

Generate local reports summarizing scan coverage, storage categories, cleanup candidates, and review outcomes.

## Packaging

Explore desktop packaging options for a smoother local app experience, including permissions, auto-updates, and platform-specific security review.

## Optional AI Assistance

Investigate privacy-preserving AI assistance for natural-language search, cleanup explanations, and custom rule suggestions without requiring file upload.
